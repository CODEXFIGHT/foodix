# Assets de documentación

Recursos gráficos compartidos por la documentación (logos, iconos, diagramas exportados, banners).

> [← Volver al índice](../README.md)

## Organización sugerida

| Archivo | Uso |
|---------|-----|
| `logo.svg` / `logo.png` | Logotipo de FoodIX para encabezados |
| `logo-dark.png` | Variante para fondos oscuros |
| `architecture.png` | Diagrama de arquitectura exportado (si no se usa Mermaid inline) |
| `roles.png` | Diagrama de roles |

Los diagramas de flujo se mantienen como **Mermaid** embebido en los `.md` para que se rendericen en GitHub sin imágenes externas. Usa esta carpeta solo para recursos binarios (logos, exportaciones) que no puedan expresarse como Mermaid.
